# C1 · CS146S 术语表（翻译一致性锚点）

> 用途：31 页课程资料中文翻译的统一译名基准。翻译时一律采用本表「标准译名」。
> 约定：
> - **产品名 / 专有名词保留英文**（Claude Code、GitHub Copilot、Google Cloud、Kubernetes、OWASP、MCP Registry 等），首次出现时可用中文括注。
> - 技术缩写（MCP、SAST、DAST、RASP、LLM、SRE、PR、CVE、RCE）保留英文，首次出现给出中文全称。
> - 一词一译，全文一致；同一概念不混用多个译名。

## 一、核心范式与 AI 协作

| 英文 | 标准译名 | 说明 / 备注 |
|---|---|---|
| Vibe Coding | 氛围编程 | 以自然语言描述意图、由 AI 生成代码的开发范式；中文常保留英文，可括注「直觉式/氛围编程」 |
| Agentic AI | 智能体化 AI | 能自主规划、调用工具、完成多步任务的 AI |
| AI Agent | AI 智能体 | 有目标、能感知环境并采取行动的 AI 系统 |
| Coding Agent | 编码智能体 | 专门辅助写代码的智能体（Devin、Claude Code 等） |
| Multi-Agent System | 多智能体系统 | 多个智能体协作完成任务的系统 |
| Human-in-the-loop | 人在回路 | 关键节点保留人工审核/介入 |
| Autonomy | 自主性 | 智能体无需人工干预的执行程度 |

## 二、Prompt 与上下文

| 英文 | 标准译名 | 说明 / 备注 |
|---|---|---|
| Prompt | 提示词 | 给模型的输入指令 |
| Prompt Engineering | 提示工程 | 设计、优化提示词的方法论 |
| Prompting Technique | 提示技巧 | 如 Chain-of-Thought、Few-shot 等具体手法 |
| Chain-of-Thought (CoT) | 思维链 | 引导模型逐步推理 |
| Few-shot | 少样本 | 用少量示例引导模型 |
| Zero-shot | 零样本 | 不给示例直接提问 |
| Prompt Injection | 提示词注入 | 攻击者通过输入劫持模型行为的攻击 |
| Prompt Hardening | 提示词加固 | 提高提示词抗注入能力的防御 |
| Instruction Hierarchy | 指令层级 | 区分系统/用户/工具指令优先级的安全机制 |
| System Prompt | 系统提示词 | 模型最高优先级的初始指令 |
| Context | 上下文 | 模型当前可用的全部输入信息 |
| Context Window | 上下文窗口 | 模型单次可处理的最大 token 数 |
| Context Engineering | 上下文工程 | 有意识地设计、裁剪、维护给模型的上下文 |
| Context Rot | 上下文腐化 | 输入变长时模型性能劣化的现象 |
| Token / Input Token | 令牌 / 输入令牌 | 文本被切分后的最小单元 |
| Long Context | 长上下文 | 超长输入的上下文场景 |
| Hallucination | 幻觉 | 模型生成看似合理但不符合事实的内容 |
| Grounding | 基于事实 / 落地 | 让模型输出锚定真实数据/来源 |
| In-context Learning | 上下文学习 | 靠上下文示例而非训练来学习任务 |
| Retrieval-Augmented Generation (RAG) | 检索增强生成 | 先检索再生成，提升事实性 |
