# Warp 与 Claude Code

Warp 是一个智能体开发环境（Agentic Development Environment）——一个融合了强大智能体的现代化终端，帮助你构建、测试、部署和调试代码。Warp 的 AI 能力由 Oz 驱动，Oz 是面向云端智能体的编排平台。

Warp 将现代化终端与 Oz（云端智能体编排平台）相结合。

## Warp

Warp 是你工作的地方——一个为「与智能体协同编程」而打造的快速、现代化终端。

核心能力：
- 智能体模式（Agent Modality）：在用于命令的简洁终端和用于多轮智能体工作流的专属对话视图之间切换。
- 现代化终端体验：光标移动、基于块（block）的导航、多行编辑、语法高亮和丰富的补全。基于 Rust 构建，性能出色。
- 代码编辑器：文件树、支持 LSP 的代码编辑器，以及交互式代码评审体验。
- 编程智能体集成：语音输入、基于终端图片的 @-选择等功能。兼容 Oz，或 Claude Code、Codex 等智能体。

## Oz：云端智能体编排平台

Oz 是驱动 Warp 全部智能特性的云端智能体编排平台。Oz 的设计目标是大规模协调智能体——理解你的代码库、自主执行任务，并适应你的工作流。Oz 原生支持多模型，让你可以灵活地为每个任务选择最佳的 LLM（大语言模型）。

Oz 有两种运行模式：

### 本地智能体（Local agents）

直接在 Warp 应用内运行，提供实时、交互式的编程协助。
- 跨代码库编写与重构代码
- 调试问题并修复错误
- 运行命令并解读结果
- 规划并执行多步骤任务

本地智能体能让你始终掌控全局。你可以审查改动、在任务中途引导智能体，并在执行前批准动作。

→ 开始使用本地智能体

### 云端智能体（Cloud agents）

Oz 云端智能体在 Warp 的基础设施（或你自己的基础设施）后台运行，用于大规模自动化。
- 触发器：响应来自 Slack、Linear、GitHub 或自定义 webhook 的事件
- 定时任务：运行周期性任务，如依赖更新或死代码清理
- 并行性：跨仓库或跨任务并发运行大量智能体
- 可观测性：每一次运行都可追踪、可审计，并能与团队共享

云端智能体适合那些不需要你即刻关注的工作，例如 PR 评审、issue 分诊、例行维护和集成驱动的工作流。

## 它们如何协同工作

Warp 和 Oz 在本地与云端开发之间提供了统一的体验：
- 同一个智能体，随处可用：无论是在 Warp 中交互式工作，还是在云端运行智能体，你使用的都是同一套底层智能体能力。
- 无缝交接：在云端启动任务，当你想亲手掌控时，可以在本地 Warp 中接管，而不会丢失进度或上下文。
- 共享上下文：Warp Drive、Rules 和 MCP 服务器在本地与云端智能体间通用，让你的团队知识与工具始终可用。
- 团队协作：共享智能体会话、审查智能体的动作，并引导正在运行的任务，无论这些任务是谁发起的。

## 多模型支持

Oz 原生支持多模型。你可以从一组精选的顶级模型中选择自己偏好的 LLM。

## 隐私与安全

Warp 已通过 SOC 2 合规认证，并与所有签约的 LLM 提供商执行零数据留存（Zero Data Retention）政策。任何客户 AI 数据都不会被保留、存储或用于训练。

Warp 的 AI 功能可以在「设置 > AI」中全局关闭。
