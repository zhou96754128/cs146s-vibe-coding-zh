# 提示技巧

提示工程（Prompt Engineering）帮助我们有效地设计与改进提示，从而让 LLM 在不同任务上取得更好的结果。

前面那些基础示例固然有趣，但本节我们将介绍更进阶的提示工程技巧——它们让我们能够完成更复杂的任务，并提升 LLM 的可靠性与表现。
